# Repository instructions

## JJP presentations
Use exclusively https://github.com/open-slide/open-slide (TypeScript/React, @open-slide/cli and @open-slide/core) for new JJP presentations. Read .agents/skills/jjp-presentation/SKILL.md. The old jjp-presentation Python renderer is legacy only; do not use it as a fallback. Keep existing road application unchanged. Scaffold OpenSlide in an isolated directory using its official CLI; preserve project briefs in projects/. Report installation, rendering and export failures honestly.
