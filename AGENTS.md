# Repository instructions

## JJP presentations

For presentation requests, use the repository's JJP workflow in
`jjp-presentation/`. Read
[the JJP Presentation Skill](.agents/skills/jjp-presentation/SKILL.md)
before authoring. Presentation work belongs in that directory or in a
task-specific output directory. Road-model work keeps its existing entry points.

Use a 16:9 canvas, an aligned editorial grid, generous margins and one clear reading
order per page. Alternate image-led pages with quieter text pages in service of
the project narrative. Use traditional Chinese or English according to the brief.
Keep whole drawing sheets visible, including title blocks, legends, scale bars
and annotations. Split dense sheets across pages only when the brief calls for
separate full sheets or an explicitly labeled detail alongside the full view.

Provide HTML, PDF and editable-text PPTX. Inspect every exported page at full
size and correct clipping, collisions, broken characters, unreadable linework,
accidental cropping and inconsistent alignment before delivery. Check HTML
separately in a browser. Record actual results and any remaining limitations.
